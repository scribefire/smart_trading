# 暗号資産データ分析ノートブック

暗号資産の価格・市場データを探索するJupyter Notebookのシリーズです。Notebookを番号順にたどると、時系列の特徴分析から市場構造の観察、シミュレーションやバックテストまで、各テーマの分析過程を確認できます。

## 分析テーマ

| Notebook | テーマ |
| --- | --- |
| 01–05 | タイムゾーンごとの値動き、長期積立の検討、恐怖指数、自己相関、異常検知 |
| 06–08 | ETF資金流入出、取引所間の価格差、取引所の貸出金利 |
| 09–10 | 運用シミュレーション、バックテスト |
| 11–12 | ハッシュレート、テクニカル指標 |
| 13–18 | 現物との価格差、DEX価格分析、約定履歴・板情報、ファンディングレート、収益機会の探索 |

Notebookはリポジトリ直下に番号付きで置かれています。関連するデータは `data/`、図は `images/` にあります。

## 見方

GitHub上でNotebookを開くと、コード、説明、出力図を確認できます。ローカルで実行する場合はPythonとJupyter環境を用意し、各Notebookで読み込むライブラリをインストールしてください。依存パッケージの固定ファイルは用意されていないため、Notebookごとに必要な環境が異なる場合があります。

## 背景

一部の分析は「スマート投資チャンネル by UKI & Hoheto」の暗号資産データ分析勉強会に関連しています。配信情報は[YouTubeチャンネル](https://www.youtube.com/@uki-hoheto)を参照してください。

本リポジトリは過去データの分析・検証用です。取引推奨や将来の運用成績を示すものではありません。
