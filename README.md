# 暗号資産データ分析ノート

価格や市場データを分析したNotebookを、テーマ別にまとめています。番号順に見ると、時系列の分析からシミュレーション、バックテストまで追えます。

| Notebook | テーマ |
| --- | --- |
| 01–05 | 値動き、長期積立、恐怖指数、自己相関、異常検知 |
| 06–08 | ETF資金流入出、取引所間の価格差、貸出金利 |
| 09–10 | 運用シミュレーション、バックテスト |
| 11–12 | ハッシュレート、テクニカル指標 |
| 13–18 | 現物との価格差、DEX、約定履歴・板、ファンディングレート、収益機会 |

Notebookはリポジトリ直下、関連データは `data/`、図は `images/` にあります。GitHub上でNotebookを開いて内容を確認できます。ローカルで動かす場合はJupyter環境を用意し、各Notebookで使うライブラリをインストールしてください。依存パッケージ一覧は置いていません。

一部のNotebookは[スマート投資チャンネル by UKI & Hoheto](https://www.youtube.com/@uki-hoheto)の勉強会に関連しています。
